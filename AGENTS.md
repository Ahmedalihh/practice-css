# AI Agent Instructions

This workspace is a small HTML/CSS practice project.

## Project structure
- `index.html` — main page markup.
- `style.css` — stylesheet used by `index.html`.
- `fonts/` — local font files referenced by CSS.

## What agents should know
- There is no build system, package manager, or test framework in this workspace.
- The project is focused on basic HTML structure and styling with CSS.
- The existing files include commented-out examples and font import experimentation.
- Keep changes minimal and preserve the current plain HTML/CSS structure unless the user asks for a redesign.

## Common tasks
- Improve or add CSS styling for existing HTML elements.
- Add semantic HTML structure or accessible form controls where appropriate.
- Fix layout, typography, and responsive behavior.
- Use the local `fonts/` folder or Google Fonts import consistently.

## How to behave
- When changing markup, avoid breaking the simple page layout or removing the existing content unless explicitly requested.
- Prefer editing `style.css` for visual changes and keep HTML modifications limited to structure and accessibility.
- Do not invent a new framework or tooling setup for this workspace.
